# FUTURE_PE_03 - AI SEO Blog & Content Cluster Generator

## Project Overview

This project was completed as part of the Prompt Engineering Internship at Future Interns.

The objective is to build a structured prompt system that generates SEO-optimized blog content and content clusters for local businesses.

The project demonstrates how AI can assist in creating keyword-focused, search-engine-friendly content that improves online visibility and supports business growth.
